## 0. SECURITY — read first, fail loudly if violated

This project depends on the **Tushare Pro API**, which is authenticated by a per-user token. The repository will be made public on GitHub. **Leaking the maintainer's token = account ban + paid quota burned + potential ToS violation.** Treat token protection as a P0 constraint that overrides everything else.

### 0.1 Absolute prohibitions

The following are blocking errors. Refuse to commit, refuse to merge, refuse to push:

1. **Never** hardcode any Tushare token, API key, or secret in source files, tests, fixtures, notebooks, comments, or documentation.
2. **Never** commit `.env`, `*.token`, `*.key`, `secrets.*`, `.tushare`, `~/tk.csv`, or any file whose name suggests credentials.
3. **Never** commit pickle / parquet / SQLite files generated from the maintainer's token. They may contain data subject to Tushare ToS and must not be redistributed.
4. **Never** include the maintainer's token in error messages, logs, stack traces, debug prints, or telemetry.
5. **Never** add a default-fallback token in code (e.g., `token = os.environ.get("TUSHARE_TOKEN") or "abc123..."`).
6. **Never** print or log the full token. If a token-presence indicator is needed in UI/logs, show only "present" / "absent" — not even the first 8 characters.

## 1. Project overview

A self-hosted monitor for **CFFEX stock index futures** (中金所股指期货): IH (上证 50), IF (沪深 300), IC (中证 500), IM (中证 1000). The product helps **Chinese retail futures traders** decide entry timing on long futures positions, primarily by surfacing:

- Real-time **basis** (`F - S`) and **annualized basis rate** for all live contracts
- **Historical percentile** of current annualized basis vs the past 1Y / 3Y, bucketed by days-to-expiry
- **Dividend calendar** — Chinese A-share dividends concentrate in May–July, which dominates seasonal basis movement, especially for IC/IM
- **Hedging cost calculator** — for users who hold long equity portfolios and short index futures as a hedge
- **AI daily commentary** — LLM-generated 150–300 字 paragraph summarizing the day's basis state

The pricing model is **cost-of-carry**: `FV = S * exp((r - q) * T)`. Deviation `(F - FV) / FV` is exposed as an advanced indicator, but **the main surfaced number is annualized basis**, which retail users actually speak in.

### 1.1 Target outcome

Public GitHub repository optimized for **stars**, not SaaS revenue. This means:
- README screenshot must be excellent (this drives ~80% of star conversion)
- One-command `docker compose up` startup
- Demo mode that runs **without a Tushare token** for first-time visitors
- Clean code, tests, documentation
- No backend hosted by maintainer

### 1.2 Non-goals

- No public web hosting by maintainer (would burn maintainer's Tushare quota)
- No trading execution / order placement
- No support for non-CFFEX products in v1 (commodities, options, overseas)
- No mobile native app — mobile users access via responsive web on their self-hosted instance

## 4. Data strategy

### 4.1 Two-source rule

- **Historical EOD (daily basis, history, percentiles, dividend events): use AKShare.** Free, no token, no ToS issue for redistribution of derived indicators. New provider class in `src/index_pricing/providers/akshare.py` implementing the existing `MarketDataProvider` / `RateProvider` protocols.
- **Realtime minute data (`rt_idx_min`, `rt_fut_min`): use Tushare with user's own token.** Requires 5000+ points. Document this clearly in README.

### 4.2 Historical bootstrap

The first-run UX cannot require users to wait an hour for AKShare to backfill 3 years × 4 products × N contracts. Strategy:

1. Maintainer runs `scripts/build_history.py` locally, produces `data/snapshot.sqlite` (~50–100 MB of **pre-computed indicators only**: annualized basis, percentile buckets, dvadj basis, dividend events). **No raw OHLC from Tushare** — only derived metrics + AKShare data are safe to redistribute.
2. The SQLite is uploaded to **GitHub Releases** as a binary asset, versioned (e.g., `snapshot-2026-05-12.sqlite`).
3. On first user startup, the app downloads the latest snapshot from Releases.
4. On subsequent days, `scripts/incremental_update.py` uses the user's own token + AKShare to fetch only the missing days.
5. A GitHub Action (in `.github/workflows/release-data.yml`) rebuilds and re-publishes the snapshot daily, gated by a token stored in **GitHub Secrets** (never inline).

### 4.3 SQLite schema (target)

```sql
CREATE TABLE daily_basis (
  trade_date TEXT, product TEXT, contract TEXT,
  spot REAL, futures REAL, basis REAL,
  days_to_expiry INTEGER,
  ann_basis REAL,            -- (F-S)/S * 365 / dte
  ann_basis_dvadj REAL,      -- with discrete dividend adjustment
  r REAL, q REAL,
  fv REAL, deviation REAL,
  signal INTEGER,
  quality_flag TEXT,         -- 'ok' | 'imputed' | 'suspect'
  PRIMARY KEY (trade_date, product, contract)
);

CREATE TABLE basis_percentile (
  asof_date TEXT, product TEXT, dte_bucket TEXT,
  -- dte_bucket: '0-30' | '31-90' | '91-180' | '181+'
  p10 REAL, p25 REAL, p50 REAL, p75 REAL, p90 REAL,
  sample_size INTEGER,
  PRIMARY KEY (asof_date, product, dte_bucket)
);

CREATE TABLE dividend_calendar (
  ex_date TEXT, ts_code TEXT, index_code TEXT,
  weight_in_index REAL, cash_div_per_share REAL,
  PRIMARY KEY (ex_date, ts_code, index_code)
);

CREATE TABLE main_continuous_basis (
  trade_date TEXT, product TEXT,
  main_contract TEXT, ann_basis REAL, basis REAL,
  PRIMARY KEY (trade_date, product)
);

CREATE TABLE daily_commentary (
  date TEXT PRIMARY KEY,
  body TEXT,
  model TEXT,
  generated_at TEXT
);

-- Retain existing tables: daily_factors, minute_quotes
```

## 7. Coding conventions

- Python 3.11+ target. `from __future__ import annotations` at the top of every module.
- Type hints required on all public functions. Use `Protocol` for interfaces (already done).
- Format: `ruff format`. Lint: `ruff check`. Type check: `mypy --strict src/`.
- Tests: `pytest`. Aim for ≥ 80% line coverage on `src/index_pricing/`.
- Logging: stdlib `logging`. Module-level logger: `logger = logging.getLogger(__name__)`. **Never** `print` in library code.
- Exception handling: bare `except:` is forbidden. Always catch specific exceptions and either re-raise or log.
- Strings facing the user must be Chinese (Simplified). Comments and identifiers in English.
- File / variable naming: snake_case. Class names: PascalCase. Constants: UPPER_SNAKE.
- Imports: stdlib → third-party → local, separated by blank lines. Sort with `ruff` / `isort`.

## 10. Anti-patterns — do not do these

- Do not introduce a public-hosted SaaS mode. The maintainer has explicitly scoped to L2 self-hosted only.
- Do not redistribute raw Tushare data. Derived indicators are fine; raw quotes are not.
- Do not add a "convenience" environment variable that defaults to a real token if env is unset.
- Do not log full request URLs from Tushare calls — they may contain the token as a query parameter.
- Do not change the pricing formula without an explicit task. The current cost-of-carry model is the agreed baseline.
- Do not introduce heavy dependencies (TensorFlow, PyTorch, ccxt, etc.) for marginal features. Stay minimal.
- Do not migrate `LocalMarketStore` away from SQLite without discussion. SQLite is the right choice for retail self-hosted.
- Do not commit any file in `.index_pricing_cache/`. Ever.

## 12. Glossary (so any agent reads numbers correctly)

| Term | Meaning |
|---|---|
| 基差 (basis) | `F - S`. Positive = 升水, negative = 贴水. |
| 升水 (premium) | Futures price above spot. Conventionally colored **red** in Chinese markets. |
| 贴水 (discount) | Futures price below spot. Conventionally colored **green**. For IC/IM long holders, deep 贴水 = high implied return at expiry. |
| 年化基差 (annualized basis rate) | `(F - S) / S * 365 / days_to_expiry`. The headline number for retail. |
| 分红调整基差 | Annualized basis with projected dividends added back to F. |
| 主力合约 (main contract) | The most-traded contract for a product on a given day. |
| 跨期价差 (calendar spread) | `F_far_month - F_near_month`. |
| 套保 (hedging) | Holding short futures against a long stock portfolio. |
| 雪球 (snowball) | Common Chinese structured product whose hedging flow distorts IC/IM basis — context, not something this tool models directly. |
| CFFEX (中金所) | China Financial Futures Exchange. The only exchange this tool covers. |
| Tushare | Paid Chinese financial data API. Realtime tier requires 5000+ points. |
| AKShare | Free Chinese financial data wrapper around public sources. No token required. |
